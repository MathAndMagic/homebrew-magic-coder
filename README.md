# homebrew-magic-coder

Dedicated Homebrew tap for the `magic-coder` CLI.

Homebrew installs currently support macOS and Linux `x86_64` and `arm64`.

## Install

```bash
brew tap MathAndMagic/magic-coder
brew install magic-coder
```

## Maintenance

This tap provides the Homebrew formula for installing and updating `magic-coder`.
